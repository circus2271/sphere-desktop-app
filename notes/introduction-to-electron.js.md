electron.js -- это, по сути, nodejs + браузер "в одном флаконе"

соответственно, у electron-приложения есть серверная и клиентская стороны. 

\+ к этому есть сторона, которая служит проводником между двумя этими сторонами

"общение" между клиентом и сервером здесь идет через подписку на события.  
это очень похоже на обычный js, где мы тоже подписываемся на события, например

```javascript
const button = document.querySelector('button')
button.addEventListener('click', function() {...})
```

в этом примере слушаются события "click', и если клик происходи, то вызывается функция-обработчик

в примере с electron.js происходит нечто похожее: 
  - кликнт слушает события, пришедшие от сервера
  - сервер слушает события, пришедшие от клиента


```javascript
// елиент триггерит событие
window.electronAPI.sendAPlaylist()

// сервер слушает и реагирует
ipcMain.on('sendAPlaylist', async () => {
    ...
})
```


```javascript
// клиент слушает события
window.electronAPI.playlistIsReadyToBeUploaded(() => {
    ...
})

// сервер отправляет
mainWindow.webContents.send('playlistIsReadyToBeUploaded')
```

но происходит их взаимодейстивие не напрямую, а через специальный модуль-прослойку, 
которая помогает клиенту и серверу обращаться друг к другу. 

## итого

electron.js приложения -- это как бы гибрид сервера и браузера.  
серверная логика находится в файле main.ts.  
клиентскя логика в файле renderer.js (который выполняется в браузерной части приложения)  
общение между клиентом и сервером происходит с помощью событий

файл preload.js служит проводником между сервером и клиентом,  
он служит как бы мостом и помогает им наладить общей контекст  
более подробно про файл preload.js можно прочитать здесь, в официальной документации к electron.js:
https://www.electronjs.org/docs/latest/tutorial/tutorial-preload
