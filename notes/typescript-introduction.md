## введение в тайпскрипт

тайпскрипт -- это javascript, но с дополнительными "фишками"

тайпскрипт не выполняется в браузере, он на этапе сборки компилируется в javascript.  
тайпскрипт исппользуется чтобы облегчить разработку и выявлять некоторые несоответствия в коде еще до запуска программы,
на этапе сборки


в тайпскрипте используются "типы" -- специальные конструкции, которые помогают компилятору понять какие объекты и какие переменные/константы должны быть в коде.  
компилятор анализирует код и выявляет возможные несоответствия (выявляет, что текущий код написан не совсем так, как это ожидается разработчиком)

пример

в javascript'е есть переменные, в них могут храниться объекты, примитивы (строки, числа) 

в javascript'е, когда мы инициализируем переменную, например:


```javascript
const name = 'Ignat'
```

мы просто пишем что переменная равна значению; в тайпскрипте мы явно указываем, что в переменной должна храниться строка:

```typescript
const name: string = 'Ignat'
```

через двоеточие от переменныой мы явно указываем её тип. в данном случае это строка, но может быть переменная и другого типа, например:

```typescript
let age: number = 109
```


### работа с типами

если у нас явно указано в коде, что переменная должна быть четко заданного типа, тогда если мы попробуем этой переменной 
присвоить "несвойественное" ей значение, тогда компилятор выдаст ошибку, например:

```typescript
let age: number = 109
age = 'Vasya'
```

здесь компилятор "ругнётся" и выдаст ошибку, что в коде что-то не то:  
там, где ожидается число вдруг откуда-то появилась строка.  
это может быть удобно для того, чтобы отлавливать возможные ошибки в коде до запуска программы и "ручного" тестирования в бразуере

#### пример чуть посложнее

указываем кастомный тип track:

```typescript
type Track = {
  duration: number,
  filename: string,
  cover: Cover
}
```

здесь у нас явно задан кастомный тип, на основе которого мы можем создавать свои собственные трэки.
(для простоты пока что не будем добавлять обложку, сделаем еёё опциональной, добавив специальный символ -- знак вопроса)

```typescript
type Track = {
  duration: number,
  filename: string,
  cover?: Cover
}

const track: Track = {
    duration: 27,
    filename: 'track25.mp3'
}
```


## introduction+

теперь попробуем понять как это может упростить работу с кодом. рассмотрим такой пример

```typescript
const track: Track = {
    duration: 27,
    filename: 'track25.mp3'
}


function getTrackDuration(simpleTrack: Track) {
    return simpleTrack.duration
}
```

здесь мы можем ожидать, что функция вернет именно число, и именно длину трэка.
если у переданного в эту функцию объекта не будет значения "duration", то тайпскрипт выдаст ошибку



кроме того, мы можем явно указавать какой типа данных функция должна вернуть:


```typescript
function getTrackDuration(simpleTrack: Track): number {
    return track.duration
}
```

здесь мы также пишем тип данных, который должна вернуть функция. поскольку track.duration у нас число, то тут всё ок.
но вот в примере


```typescript
function getTrackDuration(simpleTrack: Track): string {
    return track.duration
}
```

будет ошибка, так как track.duration не строка

## более сложный пример



```typescript
type Venicle = 'bike' | 'car'

function rideBy(venicle: Venicle) {
    if (venicle === 'bike') {
        console.log(`don't forget to take some water with you`)
    }
    if (venicle === 'car') {
        console.log(`don't forget your driver's license`)
    }
}

rideBy('car') // `don't forget your driver's license`
rideBy('bike') // don't forget to take some water with you
rideBy('train') // oops, error by now, compile time error
```

в тайпскрипте есть и более сложные штуки

## advanced

у переменной может быть более одного возможного типа

```typescript
let variable: number | string = 'Vasya'
```

здесь мы можем переопределить значение переменной, и вместо строки присвоить ей число

```typescript
variable = 10
```

если мы хотим удостовериться, что мы работаем сейчас именно с числом, то мы можем сделать проверку (также можем узнать, хранится ли в переменной строка)

```typescript
if (typeof variable === 'string') {}
if (typeof variable === 'number') {}
```

и совсем сложный пример, когда переменная может быть или объектом, или массивом объектов

```typescript
const data: Track | Track[] = [...]
```

далее, если компилятор по какой-то причине не понял объект у нас, или массив объектов, то мы можем здесь явно подсказать компилятору, что у нас, например, всё-таки массив:

```typescript
function printTrackName(data) {
    (data as Track[]).forEach(track => console.log(track.name)
}
```


(treat data as array of tracks)
